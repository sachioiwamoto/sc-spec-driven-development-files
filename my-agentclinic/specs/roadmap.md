# Roadmap (very small phases)

1. Phase 1 — MVP API + DB
   - Initialize NestJS project, TypeScript configs
   - Add SQLite + Prisma schema for agents, ailments, appointments
   - Expose basic REST API endpoints (agents, appointments)
   - Minimal UI to list agents and create appointments

2. Phase 2 — Authentication & Dashboard
   - Add simple auth (email or demo accounts)
   - Staff dashboard to view/manage agents and bookings

3. Phase 3 — Therapies & Workflows
   - Models and UI for therapies, treatment notes, and agent state
   - Support therapy scheduling and status updates

4. Phase 4 — UX polish & Marketing pages
   - Improve UI styling, accessibility, and responsiveness
   - Add marketing pages and SEO basics for demos

5. Phase 5 — Tests & CI
   - Add unit tests, Playwright end-to-end tests, and CI pipeline

6. Phase 6 — Monitoring & Deploy
   - Add logging/monitoring, deploy to a Node host or container registry

Each phase is intentionally small so students can iterate and learn.
