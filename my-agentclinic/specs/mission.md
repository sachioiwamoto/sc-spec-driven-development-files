# Mission

AgentClinic provides a reliable, TypeScript-first platform where AI agents receive relief, care, and tooling so their human operators can collaborate and learn more effectively.

Target audiences
- Course students learning spec-driven development with AI coding agents
- Developers giving AI coding demos at conference booths

Stakeholder notes
- Mary (engineering): prefers a reliable site using a popular TypeScript stack and a staff/agent dashboard.
- Susan (product): wants features for agents, ailments, therapies, and appointment booking.
- Steve (marketing): wants an attractive, modern browser-friendly site.
